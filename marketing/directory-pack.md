**Pro tips before you start**
- Use the **same canonical name, tagline, and URL** everywhere (`https://dreamforgex.ai`) so the citations are consistent — that consistency is part of what builds the entity/authority signal.
- Lead with the **free no-signup demo** (`https://dreamforgex.ai/demo/text-to-image`) — directories love "try it with no card," and it boosts click-through.
- Where a directory asks for "alternatives/competitors," name real ones (Midjourney, Leonardo AI, RunwayML, DALL·E, Adobe Firefly) — it gets you placed on those comparison pages, which is where the indexable long-tail traffic lives.
- Keep one tracking sheet (directory / date submitted / live URL / status) so you can confirm which backlinks actually went live.

### Field-mapping cheat sheet
Most directory forms ask for a subset of the above. Map them like this:

- **"Name"** → DreamForgeX
- **"Website / URL"** → https://dreamforgex.ai
- **"Tagline / one-liner / slogan"** → the tagline (≤60)
- **"Short description / summary"** → the ~100 or ~250 version (whichever fits the char limit)
- **"Description / about"** → the ~500 long version
- **"Category"** → AI Image Generator (then add AI Video + AI Audio if multi-select)
- **"Tags / keywords"** → the tag list
- **"Pricing"** → Freemium (free demo + free 50 credits on signup; paid credits after)
- **"Alternatives / competitors"** (SaaSHub, AlternativeTo) → Midjourney, Leonardo AI, RunwayML, DALL·E, Adobe Firefly
